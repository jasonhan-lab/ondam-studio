# Ondam Studio

Responsive HTML/CSS prototype. Open the root address of your Codespaces static preview (port 5500), or `/preview/`.

- `index.html`: default entry page
- `source/`: editable original HTML fragment and CSS
- `preview/`: complete browser page and mobile inspection frame
- `verification/`: checks; run `node --test verification/original.test.mjs` with Node.js 24

The contact button is a visual example; it does not send messages. No backend or deployment is included. Known title wrapping and decorative caption clipping still need refinement.
